旧系统导出工具包入口

这个页面只做目录。真正的导出流程在 exporter-pack/00_START_HERE_EXPORTER.html。

先看哪个

  1. exporter-pack/00_START_HERE_EXPORTER.html：导出执行者入口。
  2. exporter-pack/10_COORDINATOR_NOTES.html：如何向编码Agents发指令调试导出过程的问题。
  3. exporter-pack/90_DEEP_TROUBLESHOOTING_FOR_LLM.html：排障与 LLM 问题包模板。
一句话：“导出完成”不算结束。必须把 .tar.gz 和同名 .sha256 下载到 Windows，并在 Windows 本地校验。

如果你需要把问题交给 LLM

最少提供：你用的是 01_WORKBENCH_DIRECT_PASTE.txt 还是 02_WORKBENCH_DOWNLOAD_SCRIPT.txt，再加上 Workbench 最近 200 行输出。 其它更完整的清单见 90_DEEP_TROUBLESHOOTING_FOR_LLM.html。

提醒：不要把长命令拆成多段粘贴；不要跳过 .sha256；不要把“导出成功”误当成“已下载到 Windows”。
