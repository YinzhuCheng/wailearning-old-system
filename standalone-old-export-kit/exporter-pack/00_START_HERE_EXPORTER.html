旧系统导出者入口包

这个文件夹是专门给“旧系统导出执行者”的。只需要按顺序看本页，然后打开 对应的 .txt 或脚本即可，不需要在整个仓库里找文件。 本页已经把“旧服务器导出”、“下载到 Windows”、“Windows 校验”串成一条最短路径。

一眼看懂流程

你要打开哪些文件

01_WORKBENCH_DIRECT_PASTE.txt 直接粘贴到 Workbench 的完整版本。优先用它，最不容易受网络和 GitHub 访问问题影响。
02_WORKBENCH_DOWNLOAD_SCRIPT.txt 通过 GitHub raw 下载脚本后再执行。适合后续复用最新版脚本。
04_verify_export_bundle.sh 导出后，先在旧服务器上校验导出包。
05_windows_verify_bundle.ps1 把包下载到 Windows 后，用它核对 SHA256。
20_WORKBENCH_DOWNLOAD_TO_WINDOWS_VISUAL_GUIDE.html 专门讲 Workbench 里如何把迁移包下载到 Windows，并配示意图。
90_DEEP_TROUBLESHOOTING_FOR_LLM.html 出现异常时，把它和终端报错一起交给排障者或 LLM。

这个文件夹里放了什么

03_standalone_old_export.sh 真正执行导出的主脚本。
04_verify_export_bundle.sh 检查导出包结构、内部压缩包和 SHA256。
05_windows_verify_bundle.ps1 Windows 本地核对下载文件。
06_post_import_verify.sh 新系统导入后做数据库与附件对账。通常给迁移接手者使用。
20_WORKBENCH_DOWNLOAD_TO_WINDOWS_VISUAL_GUIDE.html Workbench 下载回 Windows 的独立图示说明页。
90_DEEP_TROUBLESHOOTING_FOR_LLM.html 复杂版说明，包含常见坑、兼容性和排障清单。
1

先选执行版本

优先使用 直接粘贴版。 它把主脚本完整内嵌进文本里，不依赖 GitHub，也更不容易因为外部网络失败而中断。

只有在你明确需要“每次都从 GitHub 取最新脚本”时，才用 脚本版。

2

Workbench 执行要求

必须使用 root 登录旧服务器，并且优先使用 终端连接。 阿里云官方文档明确写到：会话管理连接不支持文件管理，终端连接才支持可视化下载。

不要踩这个坑： 如果你登录后看不到文件树、看不到下载入口，或提示当前登录方式不支持文件管理， 大概率是用了会话管理连接，不是终端连接。请重新连接。
3

导出完成后不要立刻离开

导出成功后，屏幕上会给出两个路径： 

/root/wailearning-migration/old-to-new-YYYYMMDDHHMMSS.tar.gz
/root/wailearning-migration/old-to-new-YYYYMMDDHHMMSS.tar.gz.sha256

这两个文件还在旧服务器里，没有自动到 Windows。本阶段应继续在旧服务器执行： 

bash ./04_verify_export_bundle.sh /root/wailearning-migration/old-to-new-20260521120000.tar.gz
4

把文件下载到 Windows

下载这两个文件：

  • old-to-new-....tar.gz
  • old-to-new-....tar.gz.sha256

阿里云官方文档当前支持在 Workbench 文件树里右键文件下载到本地。 但如果当前连接方式不支持文件管理，或者下载速度过慢，再改用 scp、sftp 或 OSS 中转。

5

Windows 上做最后校验

powershell -ExecutionPolicy Bypass -File .\05_windows_verify_bundle.ps1 `
  -BundlePath C:\Users\you\Downloads\old-to-new-20260521120000.tar.gz `
  -Sha256File C:\Users\you\Downloads\old-to-new-20260521120000.tar.gz.sha256
当 PowerShell 输出“校验通过”后，再把这个 tar.gz 交给迁移接手者。

已经帮你规避的坑

坑 本包如何避免
长路径或长命令在 Workbench 里被自动换行截断 提供了完整复制粘贴版，且控制了操作流中的长行；不要只复制中间片段。
只导出，不知道怎么回到 Windows 本包把“旧服务器校验”和“下载到 Windows / Windows 校验”补成了标准步骤。
下载了 tar.gz，但不知道文件是否损坏 导出脚本会生成同目录 .sha256，并提供 Windows 校验脚本。
Workbench 文件管理不可用 文档明确提示要用终端连接，不要用会话管理连接。
版本兼容性不清楚 复杂版 HTML 单独写了兼容性和排障思路。
