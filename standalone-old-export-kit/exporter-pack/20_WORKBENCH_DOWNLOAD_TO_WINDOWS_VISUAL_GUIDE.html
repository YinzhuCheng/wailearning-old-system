Workbench 下载到 Windows 说明

这页只讲一件事：旧服务器已经生成迁移包后，怎么把它稳妥地下载到 Windows。 这里不再画复杂流程图，只保留最稳的步骤。

先确认你已经有这两个文件： 
/root/wailearning-migration/old-to-new-YYYYMMDDHHMMSS.tar.gz
/root/wailearning-migration/old-to-new-YYYYMMDDHHMMSS.tar.gz.sha256

最稳的下载方式

  1. 在 Workbench 里确认自己用的是终端连接，不是会话管理连接。
  2. 找到导出目录，通常是 /root/wailearning-migration。
  3. 下载同名的两个文件：.tar.gz 和 .sha256。
  4. 把它们放到 Windows 的一个短路径目录里，例如 C:\Users\you\Downloads\wailearning\。
  5. 运行 05_windows_verify_bundle.ps1 做本地校验。
最容易踩的坑：
  • 不要只下载 .tar.gz，不带 .sha256 就无法确认是否损坏。
  • 不要在 Workbench 里粘贴很长的本地路径，路径太长时容易自动换行。
  • 如果看不到文件下载入口，先检查连接方式，不要先怀疑脚本。
校验命令示例： 
powershell -ExecutionPolicy Bypass -File .\05_windows_verify_bundle.ps1 `
  -BundlePath C:\Users\you\Downloads\wailearning\old-to-new-20260521120000.tar.gz `
  -Sha256File C:\Users\you\Downloads\wailearning\old-to-new-20260521120000.tar.gz.sha256
