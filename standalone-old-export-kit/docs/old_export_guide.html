旧系统独立导出说明

本工具包用于从旧系统服务器导出迁移包，不要求旧系统仓库更新。 只要可以在阿里云 Workbench 以 root 登录旧服务器，通常就可以执行。

优先使用哪一个文件

文件 用途
01_WORKBENCH_COPY_PASTE_EXPORT.txt 首选。完整复制粘贴即可执行，不依赖旧系统仓库，也不依赖下载脚本。
02_WORKBENCH_DOWNLOAD_SCRIPT_EXPORT.txt 脚本版。会从公开 GitHub 仓库下载 scripts/standalone_old_export.sh 后执行。
scripts/standalone_old_export.sh 真正的导出脚本。可以手动上传到服务器后执行。

整体迁移思路

  1. 在旧系统服务器导出一个 tar.gz 迁移包。
  2. 迁移包内包含数据库 dump、uploads 附件、旧环境和部署配置快照。
  3. 把 tar.gz 复制到新系统服务器。
  4. 新系统用导入脚本恢复数据库，再解压附件到新系统上传目录。
  5. 新系统 bootstrap 做兼容性补齐，例如新表、新字段和默认数据。
  6. 最后用页面或接口核对学生、课程、作业、通知、附件是否正常。

为什么不能只导出数据库

旧系统不是所有资料都在数据库里。数据库通常保存用户、学生、班级、 课程、作业、通知、成绩等结构化数据，也保存附件 URL 和文件名。 但用户上传的真实文件通常在服务器文件系统的 uploads 目录中。如果只导出数据库，迁移后页面能看到记录，但附件会打不开。

因此本工具会同时尝试收集：

  • UPLOADS_DIR 指向的目录。
  • 旧 release 目录下的 uploads。
  • 应用根目录或 shared/uploads。
  • /opt 和 /root 下名字为 uploads 的目录。

不记得数据库密码怎么办

旧系统部署后，数据库连接串通常写在 .env.production 或 .env 中。 脚本会自动查找这些文件并读取 DATABASE_URL。 所以执行者不需要手动输入数据库密码。

如果脚本仍提示找不到 DATABASE_URL，说明旧系统部署路径 和默认路径不同。可以先在服务器执行 find /opt /root -name .env.production 2>/dev/null， 找到真实路径后，修改操作流开头的 ENV_FILE。

操作步骤

方式一：完整复制粘贴版

  1. 打开 01_WORKBENCH_COPY_PASTE_EXPORT.txt。
  2. 如旧系统路径不是默认值，修改文件顶部的路径变量。
  3. 全选整个文件，复制到阿里云 Workbench。
  4. 按回车等待完成。

方式二：下载脚本版

  1. 打开 02_WORKBENCH_DOWNLOAD_SCRIPT_EXPORT.txt。
  2. 全选复制到阿里云 Workbench。
  3. Workbench 会从公开 GitHub 下载脚本并执行。

导出包内容

文件 说明
old-system.dump PostgreSQL 自定义格式备份，用 pg_restore 导入。
old-uploads.tar.gz 尽量收集到的旧系统 uploads 文件。
old-env-file 旧环境变量快照，可能包含密码，请只交给可信迁移人员。
upload-roots-included.txt 脚本实际扫描并收集到的附件目录。
attachment-references.tsv 数据库内附件引用清单，用于核对是否有文件遗漏。
db-table-counts.tsv 导出时的旧库表统计，用于迁移后粗略对账。
systemd/、nginx/ 旧部署配置快照，用于排查旧系统路径和反代规则。

导入对接要点

  • 新系统导入时先备份新数据库，避免误覆盖。
  • 用 pg_restore 恢复 old-system.dump。
  • 把 old-uploads.tar.gz 解压到新系统 uploads 的父目录。
  • 导入后运行新系统 bootstrap，让新字段、新表和默认数据补齐。
  • 核对 db-table-counts.tsv 和新库表数量，重点看主业务表。
  • 用 attachment-references.tsv 检查附件 URL 对应文件是否存在。

常见失败与处理

现象 处理
提示不是 root 用户 Workbench 重新用 root 登录，或先切换到 root。
找不到 DATABASE_URL 确认 ENV_FILE 指向真实的旧系统 env 文件。
pg_dump 不存在 脚本会尝试安装 PostgreSQL client。若失败，先修复系统源。
导出包里附件为空 看 upload-roots-included.txt。 如果旧系统有自定义上传目录，把它填入 EXTRA_UPLOAD_DIRS。
复制粘贴后命令被截断 使用完整复制粘贴版，不要只复制中间一段。 本工具包已控制长行，避免路径被折成两段。

给 LLM 排错时要提供什么

如果导出不能一次成功，把以下材料一起给 LLM：

  • 01_WORKBENCH_COPY_PASTE_EXPORT.txt 或你实际执行的操作流。
  • Workbench 最后 200 行报错。
  • 本说明 HTML。
  • 如果已生成迁移包，提供其中的 manifest.txt。
  • 如果附件异常，提供 upload-roots-included.txt。
